# 分发与安装（把截图工具给别人用）

> 面向「要把本工具交给同事/换新电脑」的场景。三种形态按对方条件二选一即可，**首选形态 A**。

## 一句话选型

| 对方情况 | 给哪个包 | 对方要做的事 |
| --- | --- | --- |
| 只用 Windows，没装 Python（**多数同事**） | **A. 免安装单文件 exe** | 解压 → 双击 `截图工具.exe` → 完事 |
| 也用 WorkBuddy（想让 AI 自动截图） | **B. 技能包 zip** | 解压到技能目录 → 首次跑一次 `setup_env.py` |
| 自己会 Python、想改代码 | **C. 源码脚本** | `python setup_env.py` → `pythonw snapbar.py --install` |

---

## 形态 A：免安装单文件 exe（推荐）

**给对方的东西**：一个文件夹，内含 `截图工具.exe` + `README.txt` + `LICENSE.txt`。

**对方的安装步骤**（三步，无需管理员权限、无需装任何东西）：

1. 把文件夹放到任意位置（例：`D:\截图工具\`），别直接放在压缩包里运行。
2. 双击 `截图工具.exe` —— 任务栏右下角通知区域出现蓝色相机图标（图标可能被 Win11 收进 `^` 弹层，点一下 `^` 拖出来即可）。
3. 想让桌面/开始菜单也有入口、并开机自动常驻：`Win+R` 输入下面这行回车，会弹提示框告知结果。
   ```
   "D:\截图工具\截图工具.exe" --install
   ```
   想撤销：把 `--install` 换成 `--uninstall`，或在托盘图标上右键选「删除快捷方式与开机自启」。

**日常使用**：按 `F9`（全局热键，任何程序前台时都生效）或单击任务栏相机图标 → 屏幕变暗 → 左键拖拽框出要截的区域 → 松开即完成，图已进剪贴板，去微信/QQ/邮件/Word 里 `Ctrl+V` 直接粘贴。

框选时：`ESC` 或右键取消 · 双击截整个屏幕 · 60 秒不动自动取消 · 贴屏幕边缘会自动吸附。

**文件去哪了**：默认 桌面 `Screenshots\<日期>\snip_*.png`（默认值；实际以本机 `env.json` 的 `save_root` 为准）；最近一张固定副本在 `%LOCALAPPDATA%\WorkBuddySnap\last.png`（便于脚本/AI 读取）。
想换目录：改 `%LOCALAPPDATA%\WorkBuddySnap\env.json` 的 `"save_root"`（支持 `%USERPROFILE%` 这类变量，父目录自动创建）。
想换热键：同文件里的 `"hotkey"`，`F1`~`F12` 任选；写 `""`/`off`/`none` 即关闭全局热键。

### 为什么给 A 而不是 B

exe 内含 Python 运行时，对方**一个依赖都不用装**。代价是文件较大（约 20–40 MB）且可能被杀软误报（见下方 FAQ）。

## 形态 B：WorkBuddy 技能包

**给对方的东西**：`screenshot-skill.zip`。

**对方步骤**：

1. WorkBuddy 里问 AI「怎么装自定义技能」，或直接手工解压到：
   ```
   C:\Users\<对方的用户名>\.workbuddy\skills\screenshot\
   ```
2. 让对方把下面这句发给 AI（或自己执行）：
   ```bash
   python "<技能目录>\scripts\setup_env.py" --wb
   ```
   这一步会：找一个带 tkinter 的 Python → 建独立虚拟环境 → 装 Pillow/pystray/pywin32 → 写入 `%LOCALAPPDATA%\WorkBuddySnap\env.json`。
3. 装完重启 WorkBuddy 会话，技能即可被 AI 调用；想给人手入口再执行：
   ```bash
   pythonw "<技能目录>\scripts\snapbar.py" --install
   ```

**注意**：本技能里的 `SKILL.md` 使用占位路径（如 `<技能目录>`、`<tkgui 环境的 python.exe>`），不是本机真实路径；实际解释器以 `env.json` 登记为准，
`install_shortcut.py` 会自动读取它找解释器，不要再手改路径。

## 形态 C：源码脚本（会 Python 的人）

```bash
python setup_env.py            # 建环境（装到 %LOCALAPPDATA%\WorkBuddySnap\env）
python setup_env.py --check    # 只体检
pythonw snapbar.py --install   # 建桌面/开始菜单/自启入口
pythonw snapbar.py             # 常驻托盘
python snapbar.py --help       # 全部参数
```

## 换机 / 新用户必看：`setup_env.py` 干了什么

它解决的问题是：**「Python 装了但没有 tkinter」和「绝对路径写死」**。

1. **筛解释器**：逐个候选跑 `python -c "import tkinter"`，把没带 tkinter 的解释器直接淘汰（Windows 商店版 Python、部分精简版常缺）。
2. **建隔离环境**：venv 到用户目录，不污染系统 Python、不需要管理员权限。
3. **装依赖**：`pillow`（图像）、`pystray`（托盘）、`pywin32`（建快捷方式）。
4. **登记路径**：写 `%LOCALAPPDATA%\WorkBuddySnap\env.json`，后续脚本统一从这里取解释器。

自检命令（装完必跑）：
```bash
python setup_env.py --check
```
预期输出里 `tkinter / pillow / pystray / pywin32` 全为 `OK`。

## FAQ / 已知坑（踩过）

| 现象 | 原因与处理 |
| --- | --- |
| 杀软/Defender 报 exe 可疑 | PyInstaller 单文件包常见误报。**不要关杀软**；把 exe 加进「排除项」，或改用形态 B/C。分发前可先上传 VirusTotal 自证。 |
| 双击 exe 没反应、也没图标 | ① 已经在跑了 —— 单实例设计，去通知区域找图标；② 看日志 `%LOCALAPPDATA%\WorkBuddySnap\snapbar.log`。 |
| 通知区域找不到图标 | Win11 默认把新图标塞进「隐藏的图标」弹层。点任务栏 `^`，把相机图标拖到任务栏上，或在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里打开。 |
| 截的图跑到奇怪位置 | 桌面被 OneDrive 重定向了。本工具走系统已知文件夹接口取**真实桌面**，不会再造出假的 `Desktop` 目录；若对方手工指定了 `--outdir` 则以指定为准。 |
| 托盘图标不见了但进程在 | 资源管理器重启会重建托盘，图标通常自动回来；没回来就退出重开 exe。 |
| 想把入口放任务栏（不只是托盘） | Win11 **没有程序化固定接口**（实测 `taskbarpin` 返回 42）。只能人工：开始菜单搜「截图」→ 右键 → 更多 → 固定到任务栏。 |
| 装到 `C:\Program Files` 后不能截图 | 程序目录只读。本工具已把运行数据（图标/日志/临时图）放到 `%LOCALAPPDATA%`，可安全安装到任意目录，但仍建议放用户目录避免 UAC 提示。 |
| 框选时屏幕没变暗 / 闪一下就没了 | 看日志是否有「透明色不受支持」。 |
| 按 `F9` 没反应 | ① 热键被别的软件占了 —— 启动时 `RegisterHotKey` 返回错误码 **1409** 会弹窗提示；改 `env.json` 的 `"hotkey"` 换一个键（`F1`~`F12`）后重启，或临时用 `--hotkey F10`。② 托盘实例没在跑 —— 双击 exe 启动即可。 |

## 给 Agent 的分发清单（本技能维护者用）

打包步骤（本机）：

1. `setup_env.py --check` 确认环境 OK。
2. 跑 `py_compile` 四个脚本 + `--help` + `--selftest` 冒烟。
3. exe：在临时目录执行
   ```
   python -m PyInstaller --onefile --noconsole --name SnapTool \
     --icon <技能>\assets\snapbar.ico \
     --paths <技能>\scripts --add-data "<技能>\assets;assets" \
     --hidden-import shot --hidden-import pystray._win32 \
     <技能>\scripts\snapbar.py
   ```
   产物 `dist\SnapTool.exe` → 改名为 `截图工具.exe`。
4. 组装两个包：`截图工具-免安装版.zip`（exe + README.txt + LICENSE.txt）、`截图技能包-screenshot.zip`（技能包，含 README.md / LICENSE.txt）。
5. 在每个包上跑一次「干净目录解压 → 双击 → 截图 → 剪贴板」实测再交付。
